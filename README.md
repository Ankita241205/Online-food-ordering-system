# Online Food Ordering Website

## Project Overview
The Online Food Ordering Website is a web-based application developed to simplify the process of ordering food online. Users can browse food items, add them to the cart, place orders, and track order status through an interactive interface.

## Features
- User Registration and Login
- Food Menu Display
- Add to Cart Functionality
- Cart Management
- Order Placement
- Order Tracking
- Admin Panel
- Responsive User Interface

## Technologies Used

## Installation Steps

1. Install XAMPP
2. Copy project folder into:
   ```bash
   htdocs
   ```
3. Start Apache and MySQL from XAMPP
4. Import the SQL database into phpMyAdmin
5. Open browser and run:
   ```bash
   http://localhost/project-folder-name
   ```

## Database
Import the provided `.sql` file into phpMyAdmin before running the project.
